---

This repo turns a voiceover script into a 1920x1080 / 60 fps motion-graphics video. Every frame is a
deterministic function of time, rendered with three.js in Chrome. See README.md for the engine and
WORKFLOW.md for the human-facing quick start. Two people share this repo, one on Windows (`make.ps1`,
`.\make <step>`, `*.cmd` double-clicks) and one on Mac (`./make.sh <step>`, `*.command`); the steps
and names are the same. Collaboration rules (branches, testing) are in CONTRIBUTING.md: engine/tooling
changes go on `feat/` branches; a person's own videos stay on `video/` branches and are not merged.

## Pipeline (script -> video)

1. **Script**: `script/script.txt`, one display line per row (`#` lines are comments). Display words are
   what appears on screen (punctuation, arrows, numbers allowed).
2. **Pronunciation for the aligner**: `script/spoken.json` maps a display word (exactly as written,
   punctuation included) to its spoken words in CAPITALS, e.g. `"MP4": ["EM","PEE","FOUR"]`, `"—": []`.
   Plain integers and percentages are spelled out automatically. Anything else with digits or symbols
   needs an entry, or that word gets no timing.
3. **Voice**: `.\make voice` calls ElevenLabs (tools/elevenlabs.py) and writes `audio/voiceover.mp3`
   (the previous take is kept as `voiceover.prev.mp3`). Settings: `script/voice.json`. The key is in
   `.env`. Never print, log or commit the key. This uses the user's ElevenLabs credits, so run
   `.\make voice -DryRun` / `./make.sh voice --dry-run` first to show the character count, and don't regenerate without reason.
4. **Align**: `.\make align` writes `data/lyrics.json` (word timings, wav2vec2 CTC forced alignment)
   and `data/audio.json` (loudness and onsets). Check the printed timings: a word stuck at the same time
   as its neighbour usually means a missing `spoken.json` entry.
5. **Plates**: the scenes in `app/src/scenes/*.ts`, sequenced by `app/src/timeline.ts`.
6. **Preview / render**: `.\make preview` (http://localhost:5173), `.\make stills 12.5,40`,
   `.\make sheet`, `.\make draft`, `.\make render` -> `out/video.mp4`.
7. **Sound effects**: each script has its own cue sheet, `script/sfx_cues.py`, run by
   `analysis/sfx_mix.py` with helpers in scope (`cue`, `bed`, `typing`, `W(line, word)`, `cut`,
   `parts`). Put every cue on a word time that a plate animates on. Sounds are in `audio/sfx/`
   (`name_1.mp3`...). No cue sheet = voice-only mix. Then `.\make sfx` -> `out/video_sfx.mp4`.

Double-click shortcuts: `voice.cmd` / `voice.command` (voice + align), `render.cmd` / `render.command`
(final render + sfx), `setup.cmd` / `setup.command` (install). Commands that need the user's ElevenLabs
key or GPU must run on their machine, not in Claude's sandbox.
The original demo (script, voiceover, timings, timeline, cue sheet) is kept in `examples/demo/`.
The OpenVLA explainer (`scenes/vla_*.ts`, base class `scenes/_vla.ts`) is a compact example of a
full set of plates for a new ~30 s script; `_vla.ts` (VlaPlate) is the quickest starting point.

## Making plates for a new script

Plates find their words **by content** (`lineOf(ly, 'phrase')`, `wordOf(line, 'word', nth)`), so:
- Same script, new read: nothing to change; re-run voice + align and every plate re-times itself.
- New script: the old plates will throw "line not found". Write new plates:
  1. Split the script into beats of roughly 4-12 s (one idea each). Propose the split and a one-line
     visual concept per plate to the user before writing code.
  2. One file per plate in `app/src/scenes/<name>.ts`: `export default class X extends Scene`, set up
     words, camera keys and strokes in `init()` from word timings, draw statelessly from `f.t` in
     `render()`. Reuse `_vo.ts` (Cam2D camera, Plot plotter, placeRow + drawKaraoke world-space
     karaoke, gridPass graph paper, drawPen spark) and `_motifs.ts`. `frames.ts` is the shortest
     complete example; `hook.ts` and `code.ts` are the richest.
  3. Keep the house style: palette in `engine/palette.ts` (ink, bone, signal orange), fonts via
     `F.archivo`, IBM Plex Mono, Cormorant Garamond, the stroke fonts; motion is eased (`ease.*`,
     `prog`, `expo`) and keyed to word starts/ends, never to hard-coded seconds.
  4. Update `app/src/timeline.ts`: one `cut('first words of the line')` per plate, entries in order,
     the last ending at `au.duration`. Remove or keep old plate files (unused files are not loaded).
  5. Check: `cd app; bunx tsc --noEmit -p .` then `.\make sheet` or `stills` at a few times inside
     each plate, and look at the images before rendering a full video.
- Every plate must be deterministic in `t` (no `Math.random()` or `Date.now()`; use `hash`/`noise1`
  from `engine/util`), so preview and export match frame for frame.

## Layout

- `script/`: script.txt, spoken.json, voice.json (inputs you edit)
- `audio/`: voiceover.mp3, sfx/   `data/`: lyrics.json, audio.json (generated)
- `analysis/`: align_vo.py, audio_vo.py, sfx_mix.py, models/ (alignment model, 91 MB, downloaded by
  `tools/get_model.py`, not in git)
- `tools/elevenlabs.py`: ElevenLabs API client (stdlib only)
- `app/`: renderer (bun + Vite + three.js); `app/scripts/render.ts` is the offline renderer
- `out/`: renders (git-ignored)
